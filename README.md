# indexrule

Index timestamps and rule durations for scripts and CI receipts.

**Site:** https://theworker02.github.io/indexrule/

## Install / run

```bash
git clone https://github.com/theworker02/indexrule.git
cd indexrule
node src/cli.js
node --test
```
